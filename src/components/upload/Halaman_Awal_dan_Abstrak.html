ABSTRAK


Emisi gas berbahaya (karbon) dan penurunan kualitas udara di lingkungan ruangan rumah tangga sering kali tidak terpantau secara real-time, yang dapat memicu risiko gangguan kesehatan khususnya bagi kelompok sensitif seperti penderita asma, alergi, dan balita. Penelitian ini mengimplementasikan **CarbonSense**, sebuah platform pemantauan kualitas udara real-time berbasis Internet of Things (IoT) menggunakan mikrokontroler ESP32 dan sensor gas MQ-135, yang diintegrasikan dengan Large Language Model (LLM) berupa Gemini API guna memberikan rekomendasi penanganan kedaruratan secara interaktif. Untuk memastikan keandalan fungsionalitas sebelum deployment, dilakukan proses pengujian perangkat lunak (*Software Testing*) otomatis menggunakan metode **Black-Box Testing** dengan teknik **Equivalence Partitioning (EP)** dan **Boundary Value Analysis (BVA)**. Pengujian ini diotomatisasikan penuh menggunakan tools **Selenium IDE** dan **Selenium WebDriver** di atas peramban Microsoft Edge.

Fokus pengujian diarahkan pada 13 modul fungsional utama, meliputi alur autentikasi login/register, penyelesaian kuesioner onboarding profil AI, mekanisme penautan perangkat (*QR Code Device Binding*), streaming parameter telemetri sensor ke Firebase Realtime Database, asisten obrolan mitigasi AI, navigasi histori grafik tren kualitas udara, ekspor laporan log (Excel/PDF), serta otorisasi dasbor manajemen perangkat admin. Hasil dari eksekusi 38 skenario kasus uji yang dirancang menunjukkan tingkat keberhasilan sebesar **100% (38 dari 38 kasus uji lulus/pass)**. Defect pada sistem berupa celah validasi panjang password minimal 6 karakter serta pencegahan penautan perangkat ilegal menggunakan ID tidak terdaftar telah berhasil diperbaiki secara tuntas. Dapat disimpulkan bahwa sistem CarbonSense telah memenuhi standar fungsionalitas yang andal dan siap digunakan sebagai solusi cerdas pemantau kualitas udara di lingkungan rumah tangga.

Kata Kunci: Kualitas Udara, IoT, ESP32, MQ-135, Large Language Model (LLM), Black-Box Testing, Selenium, Firebase.

ABSTRACT


Hazardous gas emissions (carbon) and indoor air quality degradation in households are often not monitored in real-time, posing significant health risks, especially to sensitive groups such as asthma sufferers, allergy patients, and infants. This study implements **CarbonSense**, an Internet of Things (IoT)-based real-time air quality monitoring platform using the ESP32 microcontroller and the MQ-135 gas sensor, integrated with a Large Language Model (LLM) via the Gemini API to provide interactive emergency mitigation recommendations. To ensure functional reliability prior to deployment, automated software testing was performed using the **Black-Box Testing** method with **Equivalence Partitioning (EP)** and **Boundary Value Analysis (BVA)** techniques. The testing process was fully automated using **Selenium IDE** and **Selenium WebDriver** on the Microsoft Edge browser.

The testing focus was directed at 13 core functional modules, including user authentication login/register, completion of the AI profile onboarding questionnaire, the device binding mechanism via QR Code, real-time sensor telemetry streaming to the Firebase Realtime Database, the AI mitigation chat assistant, historical air quality trend chart navigation, export of log reports (Excel/PDF), and the admin device management dashboard authorization. The execution results of the 38 designed test case scenarios demonstrated a success rate of **100% (38 out of 38 test cases passed)**. Identified system defects, such as the minimum 6-character password validation and the prevention of unauthorized device binding using unregistered IDs, were successfully resolved. In conclusion, the CarbonSense system has met reliable functional requirements and is ready to be deployed as a smart air quality monitoring solution for household environments.

Keywords: Air Quality, IoT, ESP32, MQ-135, Large Language Model (LLM), Black-Box Testing, Selenium, Firebase.
