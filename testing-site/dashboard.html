Panduan Mengaktifkan Hardware ESP32

1. Sambungkan Catu Daya Perangkat

Hubungkan kabel Micro-USB ke papan ESP32 dan adaptor 5V. Pastikan lampu LED indikator menyala.

2. Hubungkan HP/Laptop ke WiFi Alat

Cari SSID WiFi bernama "Setup_CarbonSense" lalu hubungkan untuk membuka halaman pengaturan otomatis.

3. Konfigurasikan WiFi Rumah

Pilih WiFi tempat Anda dan masukkan kata sandi. Alat akan terhubung secara otomatis.

4. Pemanasan Sensor Awal (1-2 Menit)

Biarkan sensor memanaskan elemen pendeteksi selama 60 detik hingga pembacaan stabil.
